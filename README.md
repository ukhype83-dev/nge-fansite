# Nick's Gaming Emporium — fan site

An in-universe fan site for **Nick's Gaming Emporium**, a *fictional* video-game
retailer (1986–2016). Presented as the 1998 GeoCities-era tribute page of a
teenage superfan, "Todd Macy," who never took it down.

It is a companion piece to the **Nick's Gaming Emporium** database generator —
a project that builds a large, deterministic synthetic SQL Server database
telling this company's 30-year story in data:
https://github.com/ukhype83-dev/nicks-gaming-emporium

> Nick's Gaming Emporium is fictional. Everyone and everything on this site is
> a work of fiction — no real business, person, or product is depicted.

## Hosting

Static HTML — served with **GitHub Pages** (Settings → Pages → deploy from the
`main` branch, root). `index.html` is the entry point; `.nojekyll` tells Pages
to serve the files as-is.
